# Stop Slop

This edition derives from Hardik Pandya's stop-slop package at 8da1f030185bdfe8471220585162991eaeb970e9.

## Four-gate workflow

Lock the source, draft or diagnose, rewrite against the lock, and audit the final prose. Load the phrase, structure, and example references only when their flags apply. Repeat the weakest dimensions until the existing 35/50 score is met.

The seven-file repository package, README, changelog, references, and MIT license remain intact. This release edition intentionally has no real prose comparison.
